Module MathQuiz

Minijuego **MathQuiz** con problemas narrativos (paquetes/nodos/firewalls) para 8–11 años.

Mantiene la API pública:

MathQuiz.start{ rounds=3, timePer=20, onWin=function, onLose=function }

Entradas: dígitos 0–9, **Backspace** para borrar, **Enter** para enviar. Calidad de vida: - 2 intentos por ronda (con pista tras el primer error). - Tras acierto/error/tiempo, **espera Enter** para continuar (permite leer bien el feedback). - Dificultad que escala suavemente: de un paso a dos pasos.

Functions

start (opt)
Inicia el minijuego de matemáticas.

Parameters:

  • opt Opciones
    • rounds integer Cantidad de rondas (default 3)
    • timePer number Tiempo por pregunta (segundos) (default 20)
    • onWin function Callback al completar todas las rondas (optional)
    • onLose function Callback si fallas una ronda o expira el tiempo (optional)

Returns:

    MathQuiz Instancia interna (normalmente no la necesitas)

Usage:

    MathQuiz.start({
  rounds = 3,
  timePer = 20,
  onWin = function() World.onShardCollected(id) end,
  onLose = function() end
})

_timeUp ()
Maneja el fin por **tiempo agotado**. Muestra solución y entra en modo “await”.
_trySubmit ()
Intenta validar la respuesta ingresada. Si acierta: feedback positivo y pasa a “await” esperando Enter. Si falla: resta intentos, muestra pista; con 0 intentos, muestra solución y “await”.
_continueAfterAwait ()
Continúa luego del modo “await” (tras pulsar Enter). Si el último resultado fue correcto, avanza de ronda o finaliza con éxito; si no, termina con derrota.
_finish (success)
Finaliza el minijuego, limpia recursos/UI y llama los callbacks correspondientes.

Parameters:

  • success boolean `true` si se completaron todas las rondas; `false` si se falló alguna
