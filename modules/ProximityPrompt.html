Module ProximityPrompt

ProximityPrompt: muestra un prompt al acercarte y emite una señal al presionar una tecla.

Depende de: Guis, Textlabel/PrintfLabel (cualquiera), Frame, Collisions, Signal, UDim2, Connect/Fire. El prompt se activa al detectar la colisión del jugador y se oculta al salir.

Functions

new (text, key)
Crea un nuevo prompt de proximidad.

Parameters:

  • text string Texto a mostrar. Debe contener un `%s` si quieres interpolar la tecla (ej: `"Presiona %s para hablar"`).
  • key string Tecla que activa la interacción. Si se omite, usa `Config.SavedConfigs.PINTR`.

Returns:

    ProximityPrompt La nueva instancia del prompt.

Usage:

    local prompt = ProximityPrompt.new("Presiona %s para interactuar", "e")
prompt.Triggered:Connect(function() print("¡Interacción!") end)
