Class ProximityHum

ProximityHum: zumbido/loop con volumen según cercanía (en escala UDim2).

Depende de: Timer, UDim2, Player (posición en UDim2), PlayingTimers. Uso: local hum = ProximityHum.new(UDim2.fromScale(1.1, 0.4), { sound="assets/sfx/shard_hum.wav", maxDistScale=0.35 }) hum:setPos(UDim2.fromScale(1.2, 0.4)) hum:setEnabled(false) -- fade a 0, sigue vivo hum:stopAndDestroy() -- fade a 0 y destruye al llegar a silencio

Methods

Methods

proximityhum:new (pos, sound, maxDistScale, maxVol, smooth)
Crea un hum de proximidad.

Parameters:

  • pos UDim2 posición en escala (centro de la “fuente”)
  • sound string ruta del sonido (loop)
  • maxDistScale number distancia máxima en escala (0.3 = 30% ancho pantalla)
  • maxVol number volumen máximo (0-1)
  • smooth number suavizado (10-20 recomendado)

Returns:

    ProximityHum

Hace fade a 0 y destruye al llegar a silencio.
