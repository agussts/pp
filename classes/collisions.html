Methods

collisions:new (type, enabled, onHit)
Crea una nueva colisión

Parameters:

  • type El tipo de colision, puede ser "box" o "hitbox"
  • enabled Si la colision empieza activada
  • onHit La funcion que se llama cuando la colision ocurre

Returns:

    El collider creado

Usage:

    local myCollision = collisions.new("box", true, function(otherCollider)
collisions:AddTag (tagName)
Añade una etiqueta al collider

Parameters:

  • tagName Nombre de la etiqueta a añadir

Usage:

    myCollision:AddTag("nuevoTag")
collisions:RemoveTag (tagName)
Elimina una etiqueta del collider

Parameters:

  • tagName Nombre de la etiqueta a quitar

Usage:

    myCollision:RemoveTag("nuevoTag")
collisions:ReplaceTag (tagToReplace, replacement)
Remplaza una etiqueta por otra

Parameters:

  • tagToReplace Nombre de la etiqueta a reemplazar
  • replacement Nombre de la nueva etiqueta

Usage:

    myCollision:ReplaceTag("antiguoTag", "nuevoTag")
collisions:HasTag (tag)
Devuelve true o false dependiendo si el colider tiene tag pasado

Parameters:

  • tag Tag a revisar

Returns:

    (boolean) true o false dependiendo de si tiene el tag
collisions:ChangeType (typeName)
Cambia el tipo de colision de un colider

collisions:Destroy ()
Destruye el colider

Usage:

collisions:check ()
Consigue todas las colisiones que estan adentro del colider. Los "box" colider son los unicos que son repelidos al chocarse con otro, en otras palabras, no se atraviesan. Los "hitbox" colider no chocan con otros, son solo areas de deteccion.

Returns:

    Tabla con todas las colisiones entro del colider.

Usage:

  • local hitting = myHitbox:check()
  • myCollision:check()
