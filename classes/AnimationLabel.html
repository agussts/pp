Class AnimationLabel

Widget GUI para dibujar una Animation dentro del sistema de GUI.

Hereda de Guis.new() (igual que Textlabel/PrintfLabel). Soporta: fit ("none" | "contain" | "cover"), scale multiplicador y autoPlay. Se actualiza con el evento global "update".
