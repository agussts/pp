timer:after (time, callback)
Crea un temporizador que se ejecuta una vez después de un tiempo determinado.

Parameters:

  • time (number) El tiempo en segundos que durara el temporizador
  • callback (function) La funcion que se ejecutara cuando el temporizador termine

Returns:

    (timer) El temporizador creado

Usage:

    myTimer = Timer.after(5, function() print("Timer has finished!") end)
timer:every (time, callback)
Crea un temporizador que se ejecuta en intervalos regulares.

Parameters:

  • time (number) El tiempo en segundos entre cada ejecución del temporizador
  • callback (function) La funcion que se ejecutara cuando el temporizador se active

Returns:

    (timer) El temporizador creado

Usage:

    myTimer = Timer.every(5, function() print("I get printed every 5 seconds!") end)
timer:update (dt)
Actualiza todos los temporizadores, tiene que ser usado en love.update(dt)

Parameters:

Usage:
