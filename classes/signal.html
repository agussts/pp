Class signal

Clase para manejar señales y eventos.

Permite conectar, desconectar y disparar eventos. Funciona a par con connections.

See also:

    connections

Methods

signal:new () Crea una nueva instancia de signal
signal:Connect (callback) Conecta una funcion a la señal
signal:Once (callback) Conecta una funcion a la señal, pero se desconecta automaticamente despues de ser llamada una vez
signal:Disconnect (callback) Desconecta una funcion de la señal
signal:Fire (...) Dispara la señal, llamando a todas las funciones conectadas
